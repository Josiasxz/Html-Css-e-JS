Quais tags semanticas temos?

Header

O header é uma das primeiras tags semanticas que vamos falar.

Ele é feito para separar o cabeçalho do documento HTML, é ele que guarda

  • A logo
  • O titulo
  • O subtitulo
  • O menu (As vezes)

Nav

É usado para areas de navegação, ou seja, um conjunto de links importantes

  • Menu principal
  • Links de categorias

É o mapa do site

Main

É o conteudo principal da pagina

Atenção: Só deve existir um main por pagina

É so pensar no main como o protagonista da pagina HTML! Tudo que é principal está nele

Section

É uma seção tematica da pagina, geralmente tem um titulo

Article

É o conteudo independente e reutilizavel

Geralmente é:

  • Post de Blog
  • Noticia
  • Comentario
  • Produto

Se puder copiar e colar em outro site e ainda fazer sentido, provavelmente é um Article

Aside

É o conteudo complementar ou secuntadio

Pode ser:

  • Uma barra lateral
  • Anuncios
  • Informações extras
  • Links relacionados

É o bonus do site

Footer

O footer é o rodapé de uma pagina ou seção

Contem:

  • Os direitos autorais
  • Autor
  • Redes Sociais
  • Links extras
